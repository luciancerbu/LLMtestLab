### Procedural Track Generation (core algorithm):

Generate a track of **14–18 connected segments** along a forward curve in the XZ plane. Start at origin `(0, 2, 0)`; overall run ends roughly 80–120 units forward with total elevation change between -5 and +15 units.

**Segment types** (weighted random with rules):
| Type | Weight | Description |
|------|--------|-------------|
| `Straight` | 30% | 6-unit flat or slight downhill (-2°) chute |
| `CurveLeft` / `CurveRight` | 25% each | 90° arc over 6 units, banked outer edge +3° |
| `Drop` | 10% | 4-unit steep drop (-25°) into straight |
| `Jump` | 10% | Upward ramp (+20°) launching to next segment with **1–2 unit gap** |
| `Booster` | 5% | Flat pad that applies forward impulse when ball contacts |

**Placement rules (coding traps):**
1. Each segment exposes **entry socket** and **exit socket** (position + forward direction + up vector). Next segment's entry must snap to previous exit within **0.05 units** position and **5°** rotation error — regenerate segment if snap fails.
2. **No segment may place more than 12 units below y = -10** (kill plane). Regenerate track if violated.
3. **Max consecutive Jumps: 1** — never place two Jump segments back-to-back.
4. **Curve segments must alternate bias** — no more than 2 same-direction curves in a row (prevents impossible spirals).
5. After assembly, run a **validation pass:** raycast down from each segment midpoint — track must be continuous (no orphan pieces).

**Booster behavior:** `Area3D` on booster segment; on ball enter, apply `impulse = forward * 8` along track tangent.

**Kill plane:** y < -15 → status `FELL OFF`, freeze ball, show restart.

**Finish gate:** At the final segment exit socket, instance either `finish_gate.glb` (Blender) or `procedural_finish_gate` (fallback). Base flush with track surface, opening aligned with track forward (+Z). Attach an `Area3D` child (box shape ~1.2 × 1.0 × 0.8 units) for win detection — ball entering sets `FINISHED`, freeze ball, log time. Mesh is visual only; the Area3D is authoritative for wins.

### Ball Physics (tuned for spectacle, not realism):
- Mass: 0.5
- Physics material: friction 0.15, bounce 0.4
- `linear_damp = 0.1`, `angular_damp = 0.3`
- Continuous CD: `COLLISION_MODE_CONTINUOUS` (or Godot 4 equivalent) to reduce tunneling at high speed
- Launch: on **Launch Ball**, teleport to track start, zero velocities, then apply small delay (0.3 s) before applying initial impulse `forward * 3`

### Camera Follow:
- Target position: ball position - velocity.normalized() * 4 + Vector3(0, 3, 0) (behind and above)
- Lerp factor: ~5.0 * delta
- Never clip below y = 0.5 (minimum camera height)
- On `FELL OFF`, hold camera 2 s then offer reset
